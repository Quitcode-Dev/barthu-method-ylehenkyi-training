# E-006: User Dashboard, Program Delivery & Video Playback

Project: Barthu Method
Status: approved
Priority: must

Provide users with a persistent, resumable program dashboard where they can view their assigned or personalized program, watch exercise videos, track session progress, and navigate their multi-day journey. This epic delivers the core user-facing product experience that drives engagement and retention.

## Acceptance Criteria

• Authenticated members are directed to a dashboard after login
• Dashboard displays the user's current program: exercise list with video playback
• Today's session, 5-day program view, and 30-day journey are navigable (Phase 2)
• Video playback is functional within the platform via embedded external video URLs
• Users can mark sessions or exercises as complete
• Session completion is logged: user ID, session ID, date, exercises completed, duration
• Program state persists across sessions and devices — users return to find their progress saved
• Progress indicators show sessions completed and percentage of program completion
• Next session is surfaced automatically when a user returns after completing a previous session
• Users can resume a paused or interrupted program
• Dashboard is accessible and functional on desktop and mobile browsers
