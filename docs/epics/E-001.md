# E-001: User Authentication & Account Management

Project: Barthu Method
Status: approved
Priority: must

Establish the foundational identity layer of the platform, enabling users to register, log in, manage their accounts, and maintain persistent sessions across devices. This epic covers all authentication flows, password management, and account lifecycle management required to support all subsequent features.

## Acceptance Criteria

• Users can register a new account using email and password
• Users can log in and log out securely
• Users can reset their password via email
• User sessions persist across browser sessions and devices
• Account data (name, email, registration date, status) is stored securely with hashed passwords
• Unauthorized users are redirected to login when attempting to access gated content
• Account status can be set to active or inactive by admin
• Registration and login flows are accessible on desktop and mobile browsers
