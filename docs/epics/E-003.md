# E-003: NSR Assessment Engine

Project: Barthu Method
Status: approved
Priority: must

Implement the structured assessment questionnaire that captures a user's pain, stress, sleep, mobility, available time, and goals, generating either a fixed pathway assignment (Phase 1) or a scored NSR profile (Phase 2). This epic is the entry point to personalization and drives all downstream program generation logic.

## Acceptance Criteria

• Phase 1: A 5–10 question assessment questionnaire is presented to users post-registration
• Phase 2: Assessment is expanded to 15–20 questions covering pain location, stress level, sleep quality, available time, primary goal, and intensity preference
• Each question and response value is stored against the user and assessment version
• Phase 1: Responses map to one of 5–10 predefined fixed pathways
• Phase 2: Responses generate a scored NSR profile with dimension scores (pain, stress, sleep, mobility, goal)
• Phase 2: A named NSR profile type (e.g., 'Overloaded Regulator') is assigned and stored
• Assessment version is recorded with each submission to support reassessment comparison
• Assessment completion rate is measurable (≥70% target)
• Users can retake the assessment periodically to trigger program reassessment (Phase 2)
• Incomplete assessments are recoverable or prompt re-entry on next login
