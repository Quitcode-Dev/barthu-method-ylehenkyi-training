# E-005: Program Generation & Personalization Engine

Project: Barthu Method
Status: approved
Priority: must

Deliver the core recommendation logic that assembles exercise programs for users — fixed pathway assignment in Phase 1 and dynamic tag-based personalized playlist generation in Phase 2. This epic encodes the Barthu NSR Method's intellectual property in software and is the primary differentiating capability of the platform.

## Acceptance Criteria

• Phase 1: Assessment responses are mapped to one of 5–10 predefined program pathways with a defined exercise sequence
• Phase 2: A rule-based engine queries the exercise database using NSR profile dimension scores and tag-matching criteria
• Phase 2: Personalized exercise playlists are dynamically assembled per user based on their NSR profile
• Phase 2: No two users with different NSR profiles receive identical programs
• Phase 2: Programs support 5-day and 30-day structured views assembled from the exercise database
• Generated programs store: program ID, user ID, generation date, ordered exercise sequence, total duration, and NSR profile input
• Program generation accuracy is 100% validated in QA — all programs match stated goals and NSR profile
• Assessment version and generation rules used are recorded with each program for reproducibility
• Admin can define and update fixed pathway criteria and tag-matching rules without code changes
