# E-004: Exercise Library & Content Management

Project: Barthu Method
Status: approved
Priority: must

Build and maintain the tagged exercise content database and the admin interface that allows Sebastian Barthu and authorized staff to add, edit, tag, and manage exercises without developer involvement. This epic provides the content foundation that all program generation features depend on.

## Acceptance Criteria

• Exercise records store: ID, name, description, video URL, duration, intensity, progression level, and active/inactive status
• Each exercise supports multi-dimensional tags: body area, pain relief, stress reduction, sleep optimization, digestion, mindset, mobility, contraindications
• Admin interface allows creation, editing, deactivation, and deletion of exercise records
• Admin can assign and update all tag dimensions per exercise
• Video URL field supports linking to external hosted video (e.g., Vimeo)
• A minimum of 50 tagged exercises are seeded in the database at Phase 1 launch
• Admin interface requires no developer involvement for content updates
• Admin actions are recorded in an audit log (admin ID, action, entity, timestamp)
• Inactive exercises are excluded from program generation
• Admin can search and filter exercises by tag, intensity, body area, and status
