# E-007: Post-Session Feedback & Outcome Data Capture

Project: Barthu Method
Status: approved
Priority: must

Collect structured post-session feedback from users — including pain, energy, and stress ratings — after each completed session to build the outcome data layer required for future adaptive personalization and clinical evidence generation. This epic establishes the data flywheel that underpins the platform's long-term strategic value.

## Acceptance Criteria

• A feedback prompt is presented to users upon session completion
• Feedback captures: pain rating (1–10), energy rating (1–10), stress rating (1–10), and optional free-text comment
• Feedback is stored against: user ID, session ID, and date
• Feedback submission is optional but prompted consistently after each completed session
• Post-session feedback capture rate is measurable (≥50% target)
• Stored feedback is accessible to admin for reporting and analysis
• Feedback data is associated with the NSR profile and program version active at time of submission
• Users can skip feedback without blocking access to their next session
• Feedback history is retained in the user's journey record for longitudinal analysis
