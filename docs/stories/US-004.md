# US-004: Membership Payment Processing and Access Gating

Project: Barthu Method
Epic: Unassigned
Status: approved
Priority: must
Effort: L

**As a** registered user
**I want** to purchase a membership subscription through an integrated payment gateway
**So that** I can gain access to the full exercise program content on the platform

## Acceptance Criteria

- At least one active paid membership tier is available for purchase at launch
- Payment is processed via an integrated payment gateway (e.g., Stripe) — no card details are stored on the platform's own servers
- Upon successful payment, the user's account is immediately upgraded to the paid membership tier and access to program content is granted without requiring a page refresh or manual intervention
- A payment confirmation is sent to the user's registered email address within 5 minutes of a successful transaction
- If payment fails, the user is shown a clear error message specifying the reason (e.g., 'Card declined') and is given the option to retry with a different payment method
- Users without an active membership who attempt to access gated content are redirected to the payment/upgrade page with a clear explanation
- Membership status (active/inactive) and renewal date are visible to the user in their account settings page
- Subscription cancellation is available via the account settings page and prevents renewal without removing access for the remainder of the paid period
