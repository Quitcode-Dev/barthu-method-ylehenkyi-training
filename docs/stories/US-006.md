# US-006: Phase 2 NSR Assessment Scoring and Profile Generation

Project: Barthu Method
Epic: Unassigned
Status: approved
Priority: must
Effort: XL

**As a** registered user completing the expanded NSR assessment
**I want** the system to calculate a scored NSR profile from my 15–20 question assessment responses
**So that** the recommendation engine can generate a personalized exercise program that accurately reflects my pain, stress, sleep, mobility, and goals

## Acceptance Criteria

- The expanded assessment contains 15–20 questions covering at minimum: pain location, pain intensity, stress level, sleep quality, available time per session, primary goal, mobility level, and intensity preference
- Each question response maps to a numeric score contribution across one or more NSR profile dimensions
- Upon assessment completion, the system generates and stores an NSR profile record containing dimension scores for pain, stress, sleep, mobility, and goal — retrievable by user ID
- The same set of responses always produces the same NSR profile scores (deterministic scoring logic)
- NSR profile is generated and stored within 5 seconds of assessment submission
- The generated profile type name (e.g., 'Overloaded Regulator', 'Recovery Deficit') is displayed to the user on their dashboard after assessment completion
- Assessment version is stored alongside each profile record so scoring logic changes do not corrupt historical profiles
- 100% of assessment submissions result in a valid, non-null NSR profile — no submission results in an unhandled error or empty profile state
