# US-005: Admin Exercise Library Management

Project: Barthu Method
Epic: Unassigned
Status: approved
Priority: must
Effort: L

**As a** platform administrator (Sebastian Barthu or authorized staff)
**I want** to add, edit, tag, and deactivate exercises in the exercise library through an admin interface
**So that** I can keep the content library current and accurately tagged without requiring developer involvement

## Acceptance Criteria

- Admin interface is accessible via a separate, role-protected route requiring admin credentials — standard user accounts cannot access it
- Admin can create a new exercise record with the following fields: name, description, video URL, duration (minutes), intensity (low/medium/high), progression level (beginner/intermediate/advanced), and active/inactive status
- Admin can assign one or more tags to each exercise from a predefined tag taxonomy including: body area, pain relief category, stress reduction, sleep optimization, digestion, mindset, mobility, and contraindications
- Admin can edit any field of an existing exercise record and save changes — updated content is reflected to users within 60 seconds without a platform redeployment
- Admin can set an exercise to 'inactive' status, which removes it from user-facing program displays without deleting it from the database
- All admin create, edit, and deactivate actions are recorded in an audit log capturing: admin user ID, action type, entity modified, and timestamp
- The admin interface requires no command-line access, code editing, or database querying to perform any of the above actions
- A non-developer admin can add a new exercise end-to-end (create, tag, activate) in under 10 minutes without external assistance
