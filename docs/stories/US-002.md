# US-002: Phase 1 Assessment Questionnaire Completion

Project: Barthu Method
Epic: Unassigned
Status: approved
Priority: must
Effort: M

**As a** registered user
**I want** to complete a 5–10 question assessment questionnaire covering my pain location, stress level, sleep quality, available time, and primary goal
**So that** the system can assign me a program pathway that reflects my current condition and needs

## Acceptance Criteria

- Assessment contains between 5 and 10 questions covering at minimum: pain location, stress level (scale), sleep quality (scale), available time per session, and primary goal
- Each question must be answered before the user can proceed to the next — unanswered questions display a validation message
- User can navigate back to a previous question and change their answer without losing subsequent responses
- Assessment progress is auto-saved so that if the user's session is interrupted, they can resume from the last completed question upon returning
- Assessment completion triggers the system to map responses to one of the predefined program pathways
- Upon completion, user is redirected to their dashboard within 3 seconds
- Assessment completion rate is trackable in the admin interface (i.e., a record is created for both started and completed assessments)
- The assessment is completable on mobile devices with no horizontal scrolling required
