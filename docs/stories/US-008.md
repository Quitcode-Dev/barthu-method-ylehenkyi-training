# US-008: User Assessment Reassessment and Program Update

Project: Barthu Method
Epic: Unassigned
Status: approved
Priority: should
Effort: M

**As a** returning user whose condition or goals have changed
**I want** to retake the NSR assessment and receive an updated personalized program
**So that** my program continues to reflect my current state rather than my condition at initial registration

## Acceptance Criteria

- A 'Retake Assessment' option is visible on the user dashboard — it is not hidden or buried more than two clicks from the main dashboard view
- Before initiating reassessment, the user is shown a confirmation prompt warning that their current program will be replaced upon completion
- The reassessment uses the same current assessment version as new user assessments — the question set is not altered between first and subsequent assessments
- Upon completing reassessment, the system generates a new NSR profile and a new personalized program, replacing the user's previously active program
- The previous NSR profile and session completion history are retained in the database and not overwritten — only the active program pointer is updated
- The user's dashboard reflects the new program immediately after reassessment completion — no manual refresh is required
- A reassessment history list showing previous profile types and dates is visible to the user in their account or profile page
- If the user abandons the reassessment mid-way, their existing active program remains unchanged and the incomplete reassessment is discarded
