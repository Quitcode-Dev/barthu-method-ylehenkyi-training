# US-003: Fixed Pathway Program Assignment and Dashboard Display

Project: Barthu Method
Epic: Unassigned
Status: approved
Priority: must
Effort: L

**As a** registered user who has completed the Phase 1 assessment
**I want** to be assigned a predefined program pathway and see my assigned exercises on my dashboard
**So that** I can immediately begin following a structured program that matches my stated goals and condition

## Acceptance Criteria

- System maps each unique combination of assessment responses to exactly one of the 5–10 predefined program pathways — no assessment response combination results in an unassigned state
- Dashboard displays the user's assigned program name, a description of the pathway, and an ordered list of exercises
- Each exercise entry on the dashboard shows: exercise name, duration in minutes, and a thumbnail or play button linking to the video
- Video playback loads within 5 seconds on a standard broadband connection and supports pause, play, and seek controls
- The assigned program persists across user sessions — logging out and back in displays the same program without requiring reassessment
- Dashboard displays a visible indicator of overall program progress (e.g., '3 of 12 exercises completed')
- If a user has not yet completed the assessment, the dashboard redirects them to the assessment flow rather than displaying an empty program state
