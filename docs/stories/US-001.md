# US-001: User Registration and Account Creation

Project: Barthu Method
Epic: Unassigned
Status: approved
Priority: must
Effort: M

**As a** new visitor to the Barthu Method platform
**I want** to register an account using my email address and a password
**So that** I can access the platform, save my assessment results, and return to my program across sessions

## Acceptance Criteria

- Registration form requires first name, last name, email address, and password (minimum 8 characters, at least one number and one special character)
- System validates that the email address is unique — duplicate email submissions return a clear error message
- Password is stored as a hashed value; plaintext password is never persisted or logged
- Upon successful registration, the user receives a confirmation email within 2 minutes
- User is redirected to the assessment questionnaire immediately after successful registration
- If registration fails (e.g., duplicate email, invalid format), a specific inline error message is displayed without clearing valid fields
- Registration form is accessible and functional on Chrome, Firefox, Safari, and Edge on both desktop and mobile
