# US-007: Post-Session Feedback Submission

Project: Barthu Method
Epic: Unassigned
Status: approved
Priority: should
Effort: M

**As a** user who has completed a session
**I want** to rate my pain, energy, and stress levels after each session
**So that** the platform can capture my outcome data and build a foundation for future adaptive program adjustments

## Acceptance Criteria

- A feedback prompt is displayed to the user immediately upon marking a session as complete
- Feedback form requires three numeric ratings: pain level (1–10), energy level (1–10), and stress level (1–10)
- An optional free-text field is available for additional comments — this field is not required for submission
- Feedback can be submitted only once per session — attempting to resubmit displays a message indicating feedback was already recorded
- User can dismiss the feedback prompt and proceed to their dashboard — dismissal is recorded as a skipped feedback event (not the same as a submission)
- Submitted feedback is stored in the database linked to the user ID and session ID with a timestamp
- Feedback data is accessible to the admin via the admin interface and exportable (e.g., CSV) for outcome analysis
- Feedback submission confirmation is displayed to the user within 2 seconds of submission with a positive acknowledgement message
